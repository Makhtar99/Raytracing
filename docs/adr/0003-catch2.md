# 3. Use Catch2 for unit tests

## Context

We work test-first (TDD), so we need a C++ unit testing framework whose tests are short and easy to read.

Alternatives considered: GoogleTest and doctest.

## Decision

We will write unit tests with Catch2 v3 in `tests/`. CMake downloads it with `FetchContent`, pinned to tag `v3.8.1`. Each `TEST_CASE` is registered with CTest.

## Status

Proposed

## Consequences

- Test names are plain sentences and assertions are ordinary C++ expressions.
- The first configure needs internet access to download Catch2.
- Catch2 is built from source, which adds to the first build time.
- Changing framework later means rewriting the tests.
